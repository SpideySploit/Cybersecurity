Cybersecurity Hands-On Portfolio

A repository tracking practical labs, protocol analysis, and security cheatsheets.

Roadmap & Structure

Labs

- [Wireshark Traffic Analysis](labs/wireshark/README.md) - Packet analysis covering TCP 3-way handshakes, cleartext HTTP credential exfiltration, and session reconstruction.
- [Linux Fundamentals](labs/linux-fundamentals/README.md) - Host enumeration, socket discovery with netstat/ss, service auditing, and regex data extraction on Hack The Box Academy.

Cheatsheets

- [Networking Fundamentals](cheatsheets/networking-cheatsheet.md) - OSI model, TCP vs UDP, subnetting rules, and DNS resolution flow.
- [Linux Fundamentals](cheatsheets/linux-cheatsheet.md) - Process inspection, permission auditing, SUID hunting, and bash redirection pipelines.
